# Team UI: the 2.5D isometric board
Agents: raid-ui-plan (lead; owns `apps/board/` scaffold, `apps/board/src/core/`, `docs/lanes/ui-plan.md`), raid-ui-scene (owns `apps/board/src/scene/`: Three.js world, meshes, animation, picking), raid-ui-hud (owns `apps/board/src/hud/`: DOM overlays, side panel, orders bar, Library and Barracks panels, top bar), raid-ui-rev (reviewer; owns `reviews/ui.md`).
Vite + TypeScript + three.js, dev server on 127.0.0.1:4611 proxying /api to 127.0.0.1:4610. Orthographic camera at a classic isometric angle, 24 x 24 tiles, pan (drag, WASD) and zoom (wheel). Low-poly, readable, playful: a tiny strategy game, not a dashboard. The only backend it talks to is the engine.

- raid-ui-plan first step (now, within 8 minutes): scaffold the Vite app and `src/core/`: a typed store holding State (types from `contract/types.ts`), an API client (GET /api/state, POST commands), an SSE client applying events, a fixture state for when the engine is down, a tiny event bus for selection (`select(unitIds)`, `selectTarget(id)`, `hover`), and `src/main.ts` mounting `scene/` and `hud/` by one entry each (`mountScene(el, store, bus)`, `mountHud(el, store, bus)`). Commit, then tell scene and hud.
- raid-ui-scene first step (now): build `src/scene/` against that interface (use the contract types; stub the store until core lands): zone ground plates with labels, the Library (GBrain) building, the Barracks, units as little staff-carrying characters coloured by team, targets as monsters or crystals sized by severity. Click selects; right-click on a target with units selected orders them.
- raid-ui-hud first step (now): build `src/hud/`: right side panel for the selected unit (name, class, model, status, order, live activity feed, reply, message box posting /api/units/:id/message, "Open in QM" when sessionUrl is set) and for a selected target (issue, customers).
- M2: live SSE, walking with smooth interpolation, working animation. M3: box select, shift add, Cmd or Ctrl + 1..9 assign groups, 1..9 select, orders bar with countdown rings and Cancel / Adjust / Go now, autopilot toggle, ghost arrows. M4: recall (staff raised, blue beam from the Library, page icon flies to the unit) and remember (gold orb flies into the Library, Library pulses, page count ticks up); Library panel (graph, memory feed, search via engine); Barracks spawn panel. The Forge (River building, glowing anvil or foundry): panel with a form (type name, job description), progress per type (generating data, training, evaluating, ready, with a bar and stage text), eval score, and a Train unit button once ready; new units walk out of the Forge. M5: top bar (spend, tokens, agents, open issues), lighting, polish.
