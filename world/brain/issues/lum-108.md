LUM-108 (bug, severity 3) in [[components/search]]: Search shows archived projects from other workspaces.

Reported by: [[companies/northwind-freight]] via [[people/lena-okafor]]

A Northwind user saw another workspace's archived project title in the search dropdown.

## Repro
1. User belongs to workspace A only.
2. Workspace B archives a project named "Q3 Freight Plan".
3. In A, type "Q3" in search: the dropdown suggests B's archived project from the recent-results cache.

## Where to look
`search/query` (live path) and `search/recent_cache` (cached path).

## Done when
Both paths scope by `workspace_id` inside the index query; archived items are filtered in the query; a test covers the cached path.
